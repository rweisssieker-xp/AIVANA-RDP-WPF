# Story 10.5: Help Documentation & Tutorials

Status: drafted

## Story

As a user,
I want to access help documentation and tutorials,
so that I can learn how to use the application.

## Acceptance Criteria

1. **AC1:** Help documentation opens (local HTML or web)
2. **AC2:** Documentation includes: getting started guide, feature documentation, keyboard shortcuts, troubleshooting
3. **AC3:** Documentation is searchable
4. **AC4:** Welcome tutorial offered on first launch (optional)
5. **AC5:** Tutorial guides users through basic features

## Tasks / Subtasks

- [ ] Task 1: Create Help Documentation (AC: #1, #2, #3)
  - [ ] Create HTML help files or link to web documentation
  - [ ] Documentation content: Getting started, features, shortcuts, troubleshooting
  - [ ] Make documentation searchable
- [ ] Task 2: Create Help UI (AC: #1)
  - [ ] Help menu with Documentation, Tutorials, Keyboard Shortcuts options
- [ ] Task 3: Create Welcome Tutorial (AC: #4, #5)
  - [ ] Optional first-run tutorial (can be post-MVP)
  - [ ] Guide users through basic features
